# Arquivos do Projeto

## Objetivo

Este documento descreve a função dos principais arquivos utilizados no projeto AutoHire AI.

---

# Backend

| Arquivo             | Função                                                                                       |
| ------------------- | -------------------------------------------------------------------------------------------- |
| 📄 main.py          | Ponto de entrada da aplicação. Cria a instância do FastAPI e registra todas as rotas da API. |
| 📄 router.py        | Centraliza o registro das rotas da aplicação.                                                |
| 📄 home.py          | Contém a rota inicial (`/`) utilizada para verificar se a API está funcionando.              |
| 📄 requirements.txt | Lista todas as dependências Python utilizadas no projeto.                                    |
| 📄 .env.example     | Modelo das variáveis de ambiente necessárias para executar o projeto.                        |
