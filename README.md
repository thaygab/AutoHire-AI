# 🤖 AutoHire AI

Sistema inteligente para triagem automática de currículos utilizando Inteligência Artificial.

---

# 📖 Sobre o projeto

O **AutoHire AI** é um projeto Full Stack desenvolvido com o objetivo de automatizar o processo de análise de currículos.

A aplicação permitirá que recrutadores enviem currículos em PDF para que o sistema extraia automaticamente as informações dos candidatos, gere um resumo utilizando Inteligência Artificial e atribua um score de compatibilidade com a vaga.

Além de servir como projeto de portfólio, este projeto está sendo desenvolvido como material de estudo, seguindo boas práticas de arquitetura, organização, documentação e versionamento.

---

# 🎯 Objetivos

* Automatizar a análise de currículos.
* Extrair informações de arquivos PDF.
* Utilizar Inteligência Artificial para resumir perfis.
* Gerar um score de compatibilidade para candidatos.
* Disponibilizar uma interface simples e intuitiva para recrutadores.
